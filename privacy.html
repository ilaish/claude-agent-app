Claude Agent: Privacy Policy

Last updated: 2026-10-20

Claude Agent is a personal, single-user tool. Its only user is its owner.

What data it accesses

With the owner's consent, it accesses the owner's own Google Calendar, Google Tasks, Gmail and Google Drive, solely to carry out the owner's requests.

How data is stored and shared

OAuth tokens and any retrieved data are kept on the owner's private server. Data is not sold, not shared with third parties, and not used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
